## Rollback

This is a first release, so there is no previous public updater version. To withdraw it, set only the Civic Hearth product to draft and disable its own license update settings, preserving its download row and R2 object for investigation. Deactivate only the Civic Hearth demo subsite if the demo must be withdrawn. Never restore the shared network database or alter other demos.

The object map and expected hashes are retained for scoped corrections. No customer order or customer license was used for verification. No live checkout was completed during testing.
